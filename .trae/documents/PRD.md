# 内推交换平台 - 产品需求文档

## 1. 产品概述

同城求职者和在职员工之间的内推机会交换平台，通过信用体系确保双方可信，提升内推成功率。

**目标用户**：同城求职者（希望获得内推机会）、在职员工（有内推资源愿意分享）

**核心价值**：解决内推信息不对称、建立可信交换机制、提升求职效率

## 2. 功能模块

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 求职者 | 手机号注册 | 浏览职位、发布求职意向、申请内推、发起沟通 |
| 在职员工 | 手机号注册 + 在职验证 | 发布内推职位、接收申请、处理交换请求 |

### 2.2 页面结构

1. **职位广场** - 展示所有可内推职位，支持筛选和搜索
2. **交换大厅** - 智能匹配求职者与内推机会，展示推荐结果
3. **个人主页** - 用户资料、简历摘要、求职意向、信用评分
4. **消息中心** - 站内沟通、约定反馈时间、记录结果
5. **信用中心** - 信用记录、评价历史、举报管理、成功案例

## 3. 核心页面详情

### 3.1 职位广场

| 模块 | 功能描述 |
|------|----------|
| 职位列表 | 卡片展示职位信息（公司、行业、岗位、待遇区间、发布时间） |
| 筛选器 | 按城市、行业、公司规模、岗位类型筛选 |
| 搜索框 | 关键词搜索职位或公司 |
| 发布入口 | 在职员工可发布内推职位 |
| 收藏功能 | 收藏感兴趣的职位 |

### 3.2 交换大厅

| 模块 | 功能描述 |
|------|----------|
| 智能匹配 | 根据用户求职意向推荐匹配的职位和候选人 |
| 交换申请 | 申请内推名额，填写简历摘要 |
| 反馈时间约定 | 双方约定内推反馈时间 |
| 进度追踪 | 显示申请状态（待处理、处理中、已反馈） |

### 3.3 个人主页

| 模块 | 功能描述 |
|------|----------|
| 基础信息 | 头像、昵称、城市、行业、工作年限 |
| 求职意向 | 期望职位、期望城市、期望薪资范围 |
| 简历摘要 | 教育背景、工作经历、技能标签（可隐藏敏感信息） |
| 我的发布 | 我发布的内推职位、我收藏的职位 |
| 信用入口 | 查看信用评分和记录 |

### 3.4 消息中心

| 模块 | 功能描述 |
|------|----------|
| 对话列表 | 按用户展示对话记录 |
| 聊天窗口 | 实时消息、约定反馈时间 |
| 快捷操作 | 快速确认内推意向、提交评价 |
| 系统通知 | 申请状态变更、信用提醒 |

### 3.5 信用中心

| 模块 | 功能描述 |
|------|----------|
| 信用评分 | 0-100 分信用评分体系 |
| 信用记录 | 内推成功次数、失约次数、被举报次数 |
| 成功案例 | 展示平台成功内推的案例（脱敏） |
| 举报管理 | 举报失约行为，提交证据 |
| 低信用限制 | 信用分低于阈值限制发起新申请 |

## 4. 核心业务流程

### 4.1 发布内推职位流程

```
在职员工 → 填写职位信息 → 提交审核 → 发布成功
```

### 4.2 申请交换流程

```
求职者浏览职位 → 申请内推 → 在职员工审核 → 约定反馈时间 → 提交结果 → 双方评价
```

### 4.3 信用管理流程

```
用户行为（成功/失约/举报） → 信用加减分 → 低于阈值限制功能 → 申诉恢复
```

## 5. 用户界面设计

### 5.1 设计风格

- **视觉风格**：现代商务风，简洁专业，信任感强
- **主色调**：深蓝色 #1E3A5F（信任、专业）
- **强调色**：活力橙 #FF6B35（行动、热情）
- **辅助色**：浅灰 #F5F7FA、白色 #FFFFFF
- **字体**：思源黑体（中文）+ SF Pro Display（英文）
- **布局**：卡片式布局，清晰的视觉层级
- **图标**：线性图标风格，简洁现代

### 5.2 页面配色方案

| 页面 | 主色调 | 强调色 |
|------|--------|--------|
| 职位广场 | 深蓝渐变 | 橙色 CTA 按钮 |
| 交换大厅 | 紫色渐变 | 绿色成功状态 |
| 个人主页 | 灰白底色 | 蓝色信息强调 |
| 消息中心 | 绿色主题 | 消息气泡高亮 |
| 信用中心 | 金色主题 | 信用等级色彩 |

### 5.3 响应式设计

- 桌面端优先设计，兼容移动端
- 移动端底部导航适配
- 卡片网格响应式列数调整

## 6. 平台规则

### 6.1 信用评分规则

| 行为 | 信用变化 |
|------|----------|
| 内推成功 | +10 分 |
| 按时反馈 | +5 分 |
| 主动沟通 | +2 分 |
| 失约（未在约定时间反馈） | -20 分 |
| 被举报 | -30 分 |
| 恶意行为 | -50 分 |

### 6.2 低信用限制

- 信用分 < 60：禁止发起新的交换申请
- 信用分 < 40：禁止发布内推职位
- 信用分 < 20：限制登录发言功能

### 6.3 成功案例展示

- 脱敏处理（隐藏真实姓名、公司名称）
- 仅展示岗位匹配度、入职周期等正向数据
- 用户可授权展示真实案例
